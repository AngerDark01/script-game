# Offline Windows release

Build with the project Python 3.12 environment and .NET SDK, from repository root:

```powershell
D:/ACloud/.venv/Scripts/python.exe packaging/distribution/build.py --output 'D:/ACloud/auto_modules/packaging/build/new-payload'
& 'D:/ACloud/auto_modules/packaging/build/new-payload/python/python.exe' -I -B 'D:/ACloud/auto_modules/packaging/build/new-payload/app/smoke_check.py'
& 'packaging/build/installer-tools/InnoSetup/ISCC.exe' '/DPayloadDir=D:/ACloud/auto_modules/packaging/build/new-payload' '/DOutputDir=D:/ACloud/auto_modules/packaging/dist' '/DAppVersion=0.1.0' packaging/installer/AutoModules.iss
```

Download the artifacts listed in `build.py` into `packaging/build/installer-cache` before
building; SHA256 is checked. Dependency versions must match `requirements.lock`.
The builder copies only each selected distribution's recorded library files,
not the virtualenv or editable packages. All maps/configuration in this project
are treated as intentional defaults, with credentials and display coordinates
removed. Review defaults before distributing outside your own devices.

Installation is offline. Target: Windows 10/11 x64. No separate Python or .NET
installation needed. Official ViGEmBus is detected/installed by Setup, never
force-restarted, and never removed on uninstall. User data is stored under
`%LOCALAPPDATA%/AutoModules/Workbench`, separately from the install directory.
Existing map directories and configuration files are not overwritten by seeding.
LAN pairing identity is independently generated by the host on each computer.

The application and generated Setup are not commercially code-signed. Windows
may show an unknown-publisher warning; the bundled third-party driver is signed
and is checked independently. Do not bypass warnings for an untrusted download.

Development behavior is unchanged when `AUTO_MODULES_DATA_DIR` and
`AUTO_MODULES_HOST_DIR` are absent. Use those variables only for explicit isolated
tests or advanced deployments. Never share a mutable data directory between two
concurrently running workbenches.

# PoE2 双人同目标移动实验设计

## 目标与边界

在 PoE2 数据采集测试页新增独立的双人同目标移动实验。一次地图点击给 P1/P2 同一个 native 目标；两人按各自视觉位置独立规划、控制、恢复及到达。现有自动跟随与单人移动探针保持原有行为，不进入正式产品页面。

## 交互

侧栏新增 P1/P2 身份选择、开始/立即停止和两个角色的状态。开始仅建立会话，等待地图点击，不输出手柄。点击后同时给两个角色设置目标；再次点击同时重定目标。大地图显示双角色位置、同一目标和两条路线。开始其他移动实验前必须停止当前实验，反之亦然。

## 运行链路

地图及双人定位已就绪 -> 校验两个不同且当前有效的身份及两个手柄输出 -> 创建一份 `SimulatedFollowRuntime`，加入两个 `PROGRAM` follower -> 创建两个独立输出 lease -> 等待点击 -> 用现有显示/native 逆变换校验目标 -> `set_simulated_target` -> 分别 arm -> 每个 tick 使用带原始采样时间的双人视觉位置更新两个 follower -> runtime 分别给出路线/状态/输入向量 -> 输出适配器分别 apply -> 展示并记录每人的结果。

每人到达或该人的视觉位置过期时，只释放该人的输出。没有真实视觉帧时间戳、帧龄超过 700ms 或地图实例/变换整体失效时不发送输入；输出异常、停止或页面关闭时释放全部输出。小地图局部墙体接触按角色反馈给通用运行时；运行时请求全局重定位时释放全部输出，并设置 10 秒冷却，避免反复读取。视觉重定位期间保存目标；恢复到同一地图的可信双人定位后重建会话并重放目标。现有跟随和单人探针不与该会话并行。两人都到达后停止控制计时器，再次点击可重新启动。

## 复用与验收

复用现有定位、坐标转换、`SimulatedFollowRuntime`、`ProgramFollowOutput`、路线 overlay 及侧栏日志。页面只新增场景编排，不能复制规划算法或手柄协议。假手柄回归覆盖启动待命、一次点击双输出、再次点击、独立到达/丢帧、整体停止、输出异常、场景互斥和视觉恢复；不在自动测试里发送真实输入。

# PoE2 数据采集测试页设计

## 背景

PoE2 原生地形数据已经可以通过独立采集器获取并转换为 `TerrainSnapshot`，但方向校准、尺度校准和全局/局部特征匹配仍在验证阶段。当前实时地形页同时承担地图获取、监控截图、人物定位和地图叠加展示，不利于反复采样和定位问题。

本功能提供一个临时的 PoE2 业务测试页，用于稳定复现和保存采样结果，为后续方向校准与定位算法验证提供输入。该页属于 PoE2 业务层，不修改绘图模式，也不改变正式定位页的行为。

## 目标

- 在 PoE2 页面内部增加独立的“数据采集测试”页签。
- 支持显示当前绑定区域的小地图实时截图，并可手动刷新/持续预览。
- 支持独立执行当前游戏会话初始化和原生地形获取。
- 支持在内存中保留当前 `TerrainSnapshot`，并提供显式的本地测试归档保存。
- 展示原始截图、预处理图、匹配特征和当前地图，方便逐步比较。
- 每个操作都记录清晰的 PoE2 业务日志和错误信息。
- 测试页和实时定位页拥有独立的服务状态、内存快照和生命周期。

## 非目标

- 本阶段不实现方向自动校准或 45 度穷举匹配。
- 本阶段不执行人物定位、全局匹配、局部匹配、路线规划或自动移动。
- 不发送键盘、鼠标、Xbox、Host 或网络输入。
- 不修改原绘图模式的代码和行为。
- 不把临时测试归档当作正式离线地图包。

## 架构决策

### 页面组织

在现有 PoE2 业务页内部增加 `QTabWidget`（或等价的页签容器）：

```text
PoE2 地形
├── 实时地形定位      现有页面，保持现有行为
└── 数据采集测试      新页面，本设计范围
```

新页面使用独立的 `Poe2CaptureTestPage` 组件。现有 `Poe2LiveTerrainPage` 继续负责定位页，不将测试按钮散落到定位页面。

### 状态隔离

测试页拥有独立的：

- `Poe2TerrainService`；
- `MemoryTerrainStore`；
- 采集会话状态；
- 当前帧和当前地图预览状态；
- 页面定时器和停止/清理流程。

截图后端、监控配置存储、PoE2 地形转换、日志工具和归档格式复用现有底层模块。测试服务不与实时定位页共享可变的当前快照，避免测试页的清空/重新获取影响定位页。

### 采集与展示流程

```text
监控配置
  -> MonitorFrameSource
  -> 当前小地图截图
  -> 预处理/combined 特征展示

初始化
  -> Poe2TerrainService.initialize()

获取当前地图
  -> Poe2TerrainService.capture()
  -> MemoryTerrainStore.replace(snapshot)
  -> 地图展示

保存当前地图
  -> 显式写入本地测试归档
  -> 展示归档路径、实例 ID 和尺寸
```

默认截图预览只读当前绑定区域，不启动定位运行时；用户可以手动刷新，也可以启用页面内的预览定时器。预览失败时清除旧帧并显示本次错误，不能继续展示陈旧数据。

### 本地保存语义

继续复用 `TerrainDebugArchive` 的 `latest.npz`/`latest.json` 原子写入格式，保存位置保持在 PoE2 测试数据目录。页面的“保存当前地图”按钮必须要求内存中存在快照，并显示保存成功路径。后续如果需要多样本对比，再单独增加带时间戳的样本目录，不在本阶段扩展。

### 日志

所有页面操作使用现有 `auto_modules.poe2_live_terrain` 日志记录，至少覆盖：

- 测试页创建/销毁；
- 预览开始、停止、成功、失败；
- 初始化开始、成功、失败；
- 获取地图开始、成功、失败；
- 保存开始、成功、失败；
- 清空测试状态。

日志字段沿用现有 `step=...` 风格，并包含实例、尺寸、路径或异常原因等上下文。

## 验收标准

- PoE2 页面可切换到“数据采集测试”页签，现有实时地形定位页仍可正常进入和操作。
- 未绑定小地图区域时，预览按钮给出明确错误，不产生陈旧图像。
- 绑定有效时，页面能显示当前小地图截图以及预处理/匹配特征预览。
- 初始化和获取地图按钮遵守服务状态契约；未初始化不能获取。
- 获取成功后只更新测试页自己的地图预览和内存快照。
- 保存按钮能写出有效 `latest.npz` 和 `latest.json`，并显示路径。
- 测试页清空不会清除实时定位页已有快照。
- 页面隐藏、切换和主窗口关闭时，测试定时器停止且不留下后台任务。
- 单元测试覆盖页面状态流、服务隔离、错误清理和日志关键步骤。

## 后续扩展点

后续方向校准功能应作为独立的 PoE2 地图匹配适配器接入测试页，读取测试页保存的截图与地图快照，先做 45 度粗搜索，再做角度/尺度细化；不应把方向搜索直接写进通用 `MapLocalizer`。

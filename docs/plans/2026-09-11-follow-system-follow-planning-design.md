# 自动跟随系统：跟随与寻路算法设计

## 总体闭环

```text
B 最新位置 → 后方跟随目标 → A* 全局路径 → 局部路径跟踪
→ Xbox 摇杆 → A1/A2 新位置 → 误差修正/卡住恢复
```

## 跟随目标

不直接追 B 当前点。根据 B 最近位置估计移动方向，在后方生成安全距离目标；A1、A2 使用左右不同偏移，避免重叠和追尾。B 停止时沿用最近有效方向。

## 全局规划

复用现有 A* 和干净墙体地图。仅在目标变化超过阈值、路径阻塞、场景切换或卡住时重规划。地图动态变化频繁时预留 D* Lite 增量规划接口，但第一版不引入完整 ROS2。

## 局部跟踪

采用带速度约束的 Regulated Pure Pursuit：选择预瞄点，计算移动方向和摇杆幅度；转弯、靠近墙体、接近目标或定位置信度下降时自动减速。上帝视角不需要人物朝向，控制器直接输出世界坐标方向向量。

```text
direction = normalize(lookahead - current_position)
magnitude = clamp(speed_policy(distance, curvature, confidence), 0, 1)
```

输出通过现有 `VirtualGamepadActionAdapter` 和 `StickSlewLimiter`，Controller 1/2 各自独立。

## 卡住与撞墙恢复

持续输出移动 300–500 ms 而实际位移低于阈值即判定疑似卡住：立即回中摇杆，重新定位，检查局部墙体，尝试左右偏移航点并重新规划。每个角色独立计数；连续失败只停止该角色并提示。

## 状态机

```text
OFF → ARMED → FOLLOWING → REPLANNING
                     ↘ RECOVERING
FOLLOWING → RETURNING → AT_HOME
任意状态 → PAUSED / EMERGENCY_STOP
```

事件优先级：紧急停止 > 网络/定位失效 > 回城 > 用户暂停 > 卡住恢复 > 普通重规划。

## 双角色独立状态

每个控制器独立保存当前位置、目标、路径、索引、误差、卡住计时、重规划次数和 Xbox 输出。共享只读地图、B 位置和地图版本，不共享路径或恢复状态。

## 运行频率

定位 10–20 Hz，目标更新 10–20 Hz，局部跟踪 30–60 Hz，Xbox 输出 60–125 Hz，A* 事件触发。通过有界队列传递最新状态，防止计算堆积。

## 可配置参数

跟随距离、A1/A2 后方偏移、预瞄距离、最大速度、摇杆曲线、到达半径、重规划阈值、卡住时间/位移阈值、脱困方向、最大恢复次数和回城动作序列。

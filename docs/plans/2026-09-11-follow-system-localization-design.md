# 自动跟随系统：定位算法设计

## 问题模型

小地图显示全局地图的局部窗口，随人物移动而滚动。A1、A2 同时出现在该窗口中，且通过颜色或 ID 可区分。墙体匹配用于估计“当前小地图局部区域在大地图中的位置”，角色标记用于高频实时位置。

## 分层定位

### 1. 初始配准

进入地图、开始跟随或场景切换时，将当前小地图墙体边缘与大地图候选区域配准，得到 `map_origin/scale` 和置信度。大地图预先生成多级缩略图、边缘图和 tile 索引。

### 2. 增量滚动估计

正常帧将当前小地图与上一帧做相位相关、模板匹配或稀疏光流，估计局部滚动 `Δmap`，更新上一次的 `map_origin`。只在预测位置附近搜索，不扫描全图。

### 3. 局部模糊范围重定位

以预测位置为中心建立搜索窗口：

```text
predicted_origin ± search_radius
```

采用粗到细匹配：低分辨率筛选候选 tile，再对前 N 个候选做高分辨率精匹配。置信度不足时逐级扩大半径；只有连续失败才进入全局兜底。

### 4. 双角色标记检测

在同一帧小地图中分别提取 A1/A2 的颜色或 ID，使用连通域、尺寸、形状和置信度过滤，直接输出两人的小地图坐标。身份不依赖最近点匹配，因此不会因交叉移动而交换。

```text
A1_world = map_origin + A1_minimap * scale
A2_world = map_origin + A2_minimap * scale
```

## 状态与校验

每个角色保存位置、置信度、更新时间和丢失计数；地图配准保存 origin、scale、滚动速度和置信度。新结果必须满足最大位移、可行走区域和墙体约束，否则短时沿用上一结果并降低置信度。

## 触发策略

- 正常：沿用变换并高频识别颜色/ID。
- 轻微异常：扩大 ROI 或局部搜索窗口。
- 连续 3–5 帧失败：局部重定位。
- 场景切换、传送、回城或局部失败：初始配准。
- 全局搜索仅作为最后兜底，并阻塞自动移动。

## 并发与性能

一次截图、一次地图滚动估计供 A1/A2 共用；标记检测可并行。地图配准放在独立 worker，不能阻塞 Xbox 输出。使用最新值缓存，丢弃过期帧。

## 可配置参数

小地图 ROI、A1/A2 颜色或 ID、颜色容差、标记大小、搜索半径、最大扩大半径、低置信度阈值、丢失帧数、全局校准间隔和最大允许位移。

## 外部方案核对与选型

参考 ROS Nav2、Cartographer/Karto 等成熟 2D 导航实现后，适合本项目的不是完整 SLAM，而是轻量的局部相关匹配：Cartographer 的 correlative scan matching 思路可在预测位姿附近枚举平移候选，并用距离变换/占用栅格评分；Nav2 的分层规划和局部控制可直接借鉴。OpenCV 的 phase correlation 适合帧间纯平移快速估计，ORB/稀疏光流作为纹理不足或滚动异常时的备用。

推荐级联：

```text
phase correlation（最快）
  → 局部距离变换/Chamfer 相关匹配（主校准）
  → ORB/模板精匹配（异常备用）
  → 全局搜索（仅兜底）
```

该方案保留局部模糊范围、共享一次 A1/A2 地图配准，并避免引入完整 ROS2 运行时。

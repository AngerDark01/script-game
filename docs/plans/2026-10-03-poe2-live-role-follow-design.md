# PoE2 双人实时角色跟随设计

日期：2026-10-03。范围仅限 PoE2 数据采集实验页；保留现有地图点击定点移动和正式定位页行为。

## 目标与边界

- 支持 P1 手动、程序控制 P2 跟随，以及反向角色分配。
- 目标是被跟随角色的最新可信 native 地图坐标，不追历史轨迹，也不预测位移技能的落点。
- 程序角色靠近目标一定范围即停止，目标再次远离才恢复；不要求两个角色占据同一点。
- 两个角色必须处于同一地图实例。实验阶段由同一双人视觉定位帧提供位置；以后可用具有相同契约的其他设备位置源替换。
- 不增加内存轮询，不在规划器或定位器内产生手柄输入；真实输入仅在用户明确启动实验且输出角色被绑定后发送。

## 模块职责

1. 目标源适配器：从双人定位状态提取手动角色 `PositionSample`，保留角色身份、地图实例、真实截图时间与置信度。只接受新帧；位置未变也只能用真实新帧续期。目标跳变直接替换坐标，不插值。
2. 跟随距离策略：独立于定点移动参数，管理 `追赶/保持` 状态。实验初值为进入半径 12 native 单位、恢复半径 20 native 单位；半径后续根据实机日志调整。保持时输出中性，不规划新路线。
3. 跟随运行器：使用现有单角色路径规划、局部控制、墙体接触证据、卡住恢复和重定位请求。目标移动超过既有重规划阈值、角色偏离路线或路线失效时才重规划，避免每帧 A*。
4. 输出适配器：只绑定程序角色的虚拟手柄。手动角色只参与观测，不调用其 `apply/arm`；程序角色在可信目标离开保持带后接管，到达、失效或停止时中性并释放。运行器不直接调用手柄。
5. 实验页：独立选择手动角色与跟随角色，显示两人位置、动态目标、程序角色路线、距离、跟随状态与失败原因；保留地图点击目标实验。

## 运行链路

1. 用户完成双人首帧与实时定位，选择角色方向，启动角色跟随；页面核对两名不同角色、地图实例、当前定位状态、最新视觉帧与程序手柄绑定。启动前不输出运动。
2. 每次新的双人视觉帧更新两个角色的位置。手动角色位置作为目标样本发布，程序角色位置作为反馈；控制 tick 只消费最近一次样本，不能把 tick 时间写成截图时间。
3. 若距离大于恢复半径，程序角色沿用定点移动闭环向最新目标前进；若距离小于等于进入半径，清除路线、发中性并保持。两个半径之间保持前一状态，防止抖动。
4. 目标通过位移技能跳变时直接重算到新坐标的安全路线；不沿目标经过的未知路径行走。目标位置变化不足既有目标刷新距离时，继续执行仍有效的路线，由局部控制修正。
5. 目标/跟随者视觉样本超过 700 ms、定位失稳、地图实例不符、重定位进行中或输出异常时，立即中性并释放。重定位后必须从新可信帧恢复，不能复用旧目标时间戳或路线。
6. 用户停止或切换角色方向时先释放程序手柄、清除运行状态，再重新建立绑定；绝不把程序输出切到手动角色。

## 验证

- 纯运行器测试：静止目标、目标持续移动、跳变、进入/离开滞回带、相同位置的新帧续期、旧帧与跨地图拒绝。
- 页面/输出契约测试：P1/P2 双向角色映射、手动角色绝不接收程序输出、丢帧/定位失稳/重定位中释放、停止与异常释放、点击定点实验不回归。
- 离线回放：用已保存的双人定位样本确认位置、目标、路线和日志时序；不把回放通过称为实机通过。
- 实机验收由用户启动实验：两种方向分别验证起步、靠近停止、目标再次走远后追赶、位移技能跳变，以及停止后手柄释放。记录目标帧时间/年龄、距离、路线重规划原因、控制状态与输出状态。

# PoE2 监控配置复用与实时地形页面设计

## 目标

参考绘图模式中已经验证的监控区域配置体验，在 PoE2 业务域内独立复刻一套监控配置工作台；PoE2 页面保留独立的本地多配置、在线地图内存会话和人物定位展示。原绘图模式不改、不回接新模块。

## 已确认的设计决策

1. 采用“PoE2 独立监控配置模块”的方案，参考并复用绘图模式的成熟交互，但不改动或继承整个 `MappingWidget`。
2. 监控截图底层始终是矩形数组。
3. 正方形模式使用完整矩形区域。
4. 圆形模式仍截取外接正方形，但生成圆形有效区域遮罩；圆外像素不参与识别、匹配和定位。
5. 监控配置暂不绑定 Windows 用户、应用用户或游戏账号，只提供本地多配置。
6. 每个配置保存完整的监控与识别参数，但不保存地图、人物位置、运行状态或临时帧。
7. PoE2 地图由在线采集得到，存入当前运行内存；本阶段不保存地图文件。
8. 本阶段只做地图获取、监控、全局/局部定位和可视化，不执行键盘、鼠标、Xbox、Host 或自动移动。

## 分层边界与兼容策略

```text
通用空间/采集能力（只新增稳定、无业务语义的能力）
  CaptureShape、CaptureGeometry、CircularMask、SquareMask
                                      ↓
PoE2 独立监控配置 UI（参考绘图模式实现）
  PoE2 画框、中心点、截图大小、形状、识别参数、预览和 profile 编辑
                                      ↓
PoE2 业务组合
  在线地形、内存地图、人物定位

绘图模式保持原有实现和数据流，不接入 PoE2 profile 或圆形遮罩改造。
```

- 通用模块不得导入 PoE2、绘图模式或具体游戏对象。
- 新增通用底层能力只有在契约稳定时才创建；不得为了复用 UI 而修改现有绘图模块。
- 绘图模式继续拥有自己的地图拼接、地图保存和配置生命周期，现有代码保持不变。
- PoE2 feature 继续拥有采集服务、定位 runtime、内存地图和 PoE2 日志。
- PoE2 UI 组合层负责注入服务、配置存储和显示模型；PoE2 选择器、配置面板和 profile 编辑器放在 PoE2 UI 目录下。

## 本地配置模型

PoE2 配置由本地 profile store 管理，暂不包含 `user_id`：

```text
data/poe2/monitor_profiles/
  profiles.json
  <profile-id>.json
```

每个 profile 至少包含：

- `id`、`name`、`created_at`、`updated_at`；
- 监控区域或人物中心点；
- 截图大小；
- `shape: square | circle`；
- 圆形有效半径/遮罩参数；
- 屏幕、坐标空间和 DPI；
- 采样间隔；
- 全局匹配阈值、局部搜索半径；
- HSV、特征增强和识别参数。

不包含：地形快照、拼接地图、人物当前位置、监控开关、错误信息、临时帧。

用户可以新建、复制、重命名、保存、切换和删除 profile。监控运行期间禁止切换或编辑当前 profile；停止监控后恢复编辑。

## 页面排版

PoE2 页面复用绘图模式的左右分栏和分组控件风格：

```text
顶部：当前配置选择 / 新建 / 复制 / 重命名 / 保存 / 删除

左侧滚动区：
  1. 监控区域：画框、中心点、截图大小、正方形/圆形、圆形半径
  2. 地图获取：初始化、获取当前地图、清空当前会话
  3. 监控控制：开始、停止、采样间隔
  4. 识别参数：全局阈值、局部半径、HSV、特征参数
  5. 日志与诊断

右侧展示区：
  实时监控小地图：原始截图、有效区域遮罩、识别结果
  当前获取地图：地形图和人物当前位置叠加
  人物位置状态：全局/局部坐标、置信度、匹配模式、帧耗时、失败原因
```

人物位置直接叠加在当前内存地图上，状态区只展示诊断信息；本阶段不绘制导航路线。

## 生命周期

1. 选择或创建本地 profile。
2. 使用 PoE2 独立选择器完成画框或人物中心点配置。
3. 保存 profile。
4. 点击“初始化”建立当前 PoE2 采集会话。
5. 点击“获取当前地图”，将 `TerrainSnapshot` 放入内存并展示。
6. 点击“开始监控”，runtime 使用当前 profile 采集小地图。
7. 首帧执行全局定位，后续帧使用模糊位置进行局部重定位。
8. 定位结果更新小地图预览、地图人物标记和状态区。
9. 停止监控或清空会话时释放运行状态，但不删除本地 profile。

## 验证边界

- 纯模块测试：形状、遮罩、profile 序列化、原子保存、配置切换。
- UI 合约测试：画框/中心点/形状控件、按钮状态、左右布局、定位标记更新。
- PoE2 集成测试：初始化、地图获取、内存快照、runtime 状态到 UI 的显示。
- 不运行真实游戏、真实输入、Host、LAN 或网络同步测试。

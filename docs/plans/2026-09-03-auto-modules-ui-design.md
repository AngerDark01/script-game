# auto_modules 导航 UI 视觉优化设计

## 背景

导航页的小窗模式当前使用四条横向工具栏和一个固定高度的地图视图。窗口变高时，多余高度被工具栏吸收，地图仍限制在 380px，造成大面积留白；窗口变窄时，按钮文本又把窗口最小宽度撑大。空地图状态、运行状态和地图覆盖物也缺少清晰的视觉层级。

## 目标

1. 小窗模式在 460px 左右宽度下可用，且不再出现工具栏被垂直拉伸。
2. 地图成为导航页的视觉主体，空状态也能明确告诉用户下一步。
3. 用统一的深色战术主题区分主操作、运行状态、警告和危险操作。
4. 核心流程按状态呈现：加载地图 → 设置起点 → 开始定位 → 自动到出口。
5. 地图标记同时使用颜色、形状和文字，避免只靠颜色传达含义。

## 方案

### 页面结构

- 顶部保留绘图/导航模式切换，改为清晰的分段选中状态。
- 导航页顶部为地图选择、地图加载状态和“更多”入口。
- 中部地图画布自适应占据剩余空间；未加载时显示带主按钮的空状态。
- 地图下方保留核心动作区，只突出一个当前主操作。
- 坐标、定位置信度、事件和导航消息拆为紧凑 HUD，而不是底部一行长文本。
- 路线编辑、参数、事件管理和样本工具在小窗模式下收进更多面板；完整模式下可展开显示。

### 响应式断点

- 460–720px：悬浮小窗，只展示地图、状态和核心动作；工具按钮使用图标/短标签及工具提示。
- 720–1100px：标准布局，显示地图选择、核心动作和可折叠路线工具。
- 1100px 以上：工作台布局，地图占主要区域，辅助工具以侧栏或可折叠面板呈现。

### 视觉语言

- 应用背景 `#0B1220`，面板 `#111C2B`，地图画布 `#071019`。
- 主操作使用蓝青色，运行/已定位使用绿色，警告使用橙色，停止/失败使用红色。
- 工具栏控件固定 36–40px 高，使用统一间距、焦点描边和禁用态对比度。
- 地图路径和标记使用深色外描边；玩家、出口、必经点、途经点采用不同形状并提供图例。
- 地图覆盖物线宽使用 cosmetic pen，保证缩放时屏幕可读性稳定。

## 实施边界

- 只修改 `gui/main_window.py`、`gui/modes/navigation/ui/`、`gui/modes/navigation/presentation/` 以及主题资源。
- 不修改 `core/` 的定位、拼接、路由和事件算法。
- 先完成布局和空状态，再完成主题和 HUD，最后调整地图覆盖物与交互反馈。

## 验收标准

- 在 500×700、800×800、1600×1000 三种窗口尺寸下无大面积异常留白，地图区域随窗口合理伸缩。
- 小窗模式的实际最小宽度不超过 520px，核心按钮不被裁切。
- 未加载地图时，地图区域有明确的下一步操作；加载、定位、导航和失败状态均有明显反馈。
- 关键按钮可通过键盘 Tab 访问，焦点可见；状态含义不只依赖颜色。
- 现有导航和地图渲染测试不受影响，应用可在 Qt offscreen 模式构造主窗口。

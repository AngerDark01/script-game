# PoE2 独立监控配置设计

## 状态

已确认设计，等待拆分实现任务。

## 背景

当前主窗口同时承载开发工作台和正式业务能力：页面 1、2 主要用于绘图与导航开发，手柄、局域网和 PoE2 属于正式业务方向。PoE2 后续需要监视游戏内小地图、加载实时地形并进行定位，因此需要独立的监控区域和运行配置。

PoE2 仍然作为当前主窗口中的一个页面开发和测试，不在本阶段拆分独立产品启动器。但 PoE2 不得依赖页面 1、2 的页面实例、导航配置或导航运行生命周期。

## 设计目标

- PoE2 页面继续注册在当前 `MainWindow` 中。
- PoE2 提供独立的非模态监控配置子窗口。
- PoE2 拥有独立的配置模型、配置存储和运行状态。
- 配置窗口可复用通用的区域选择和截图能力，但不复用导航页配置对象。
- PoE2 可以在页面 1、2 不创建、不显示甚至后续移除时继续运行。
- 当前地图、定位结果和帧缓存只保存在 PoE2 运行时内存中；测试归档仍可由显式调试适配器提供。
- 定位运行期间锁定监控配置，修改后在下一次启动定位时生效。

## 非目标

- 本阶段不实现自动跟随、路径规划、Xbox 输入或局域网事件同步。
- 不将 PoE2 配置写入 `NavConfig` 或旧导航配置文件。
- 不与页面 1、2 的监控区域自动同步。
- 不建立全局监控配置档案系统。
- 不在本阶段拆分新的产品主窗口或删除开发工作台页面。

## 架构边界

```text
MainWindow
  ├── 页面 1/2：开发工作台
  ├── GamepadPage：正式业务
  ├── LanPage：正式业务
  └── Poe2LiveTerrainPage：PoE2 正式业务组合根
        └── Poe2MonitorConfigDialog：PoE2 独立配置窗口

共享底层能力
  ├── 屏幕区域截图
  ├── 物理/逻辑坐标转换
  ├── 区域选择覆盖层
  ├── 小地图帧来源
  ├── 玩家识别
  └── 全图/局部匹配
```

PoE2 业务层允许依赖共享底层能力，但不得依赖以下导航业务对象：

- `NavigationModeWidget`
- `NavConfig`
- `NavParametersDialog`
- 导航页定时器与运行循环
- `NavigationCore`
- 导航路径规划、事件执行和输入生命周期

## 配置模型

新增 PoE2 专属配置模型，至少包含：

- `capture_rect`：物理桌面坐标中的截图矩形；
- `coordinate_space`：截图矩形的坐标空间；
- `screen_id`：监控区域所属屏幕标识；
- `dpi_scale`：区域选择和截图之间的缩放信息；
- `player_marker_position`：玩家标记在小地图截图中的位置；
- 定位所需的搜索半径、匹配阈值和采样间隔。

该模型由 PoE2 自己加载和保存，建议存放在独立的 PoE2 配置目录。配置文件可以持久化，因为它属于用户设置；当前地图和定位状态不写入配置文件。

## 配置窗口

PoE2 页面增加“监控配置”入口，打开非模态 `QDialog` 或 `Qt.Tool` 工具窗口。窗口职责限定为：

- 选择小地图区域；
- 显示当前区域截图预览；
- 执行一次测试截图；
- 显示截图尺寸和坐标信息；
- 编辑 PoE2 定位相关参数；
- 保存或取消修改；
- 可选的窗口置顶开关。

区域选择控件可以复用通用覆盖层的交互，但结果必须写入 `Poe2MonitorConfig`，不能回写导航配置。

## 运行生命周期

```text
未配置
  -> 已配置
  -> 已初始化
  -> 已加载地图
  -> 定位运行中
  -> 已停止
```

规则：

- 初始化和获取地图不依赖导航页是否运行；
- 开始定位前读取一次完整的 PoE2 配置快照；
- 定位运行期间配置窗口中的关键字段不可编辑；
- 停止定位后才允许修改监控区域和匹配参数；
- 修改后的配置不影响当前运行实例，下一次开始定位时重新加载；
- 停止定位必须释放截图循环和相关帧缓存。

## 共享能力的使用方式

共享的是明确的能力接口，而不是共享业务状态：

- 截图后端提供区域截图能力；
- 区域选择组件只产生一个区域结果；
- 坐标转换模块负责物理坐标、逻辑坐标和截图局部坐标转换；
- 识别器和匹配器接收帧与参数并返回结果；
- PoE2 服务负责组合这些能力并维护自己的状态。

PoE2 不应读取或修改 `AppContext` 中面向导航的可变监控字段来实现配置同步。若现有底层接口不足，应提取窄小、业务无关的接口，而不是让 PoE2 直接调用导航页面方法。

## 测试边界

至少覆盖：

- PoE2 配置默认值、保存、加载和非法值拒绝；
- 配置窗口不会修改 `NavConfig`；
- 定位运行时配置控件被锁定；
- 停止定位后截图循环被释放；
- PoE2 页面可以在不创建导航页的测试夹具中初始化；
- 区域选择结果可以转换为截图矩形和玩家局部坐标；
- 共享截图与识别接口的契约测试；
- 现有导航页测试保持通过。

真实桌面截图、PoE2 进程和真实输入仍然属于显式实机验证，不纳入默认单元测试。

## 验收标准

1. 在当前主窗口中打开 PoE2 页面，可以独立打开监控配置子窗口。
2. PoE2 配置保存后，关闭并重新打开页面仍能恢复自己的配置。
3. 修改 PoE2 配置不会改变页面 1/2 的配置。
4. 页面 1/2 不创建时，PoE2 的服务和页面单元测试仍然通过。
5. 定位运行时无法修改监控区域，停止后可继续编辑。
6. PoE2 当前地图和定位状态只存在于内存服务中，不写入旧地图包目录。
7. 底层共享模块不出现 PoE2 或导航业务分支。

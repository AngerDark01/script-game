# Approved offline installer design

## Goal
Deliver a Windows x64 offline Setup.exe containing the complete workbench, a relocatable Python runtime and its required pinned dependencies, the self-contained virtual-controller host, and the verified official ViGEmBus installer.

## User-approved behavior
One installer and one desktop startup entry; no Python, pip or .NET SDK setup on the receiving PC. Automatically detect/install the virtual Xbox bus when missing, verify the driver/backend, show failure or reboot-required distinctly, never silently reboot. Bundle only a verified upstream signed driver, not another project's unknown executable. Existing maps/profiles remain intact. Pairing identities, credentials, development caches and unrelated virtualenv packages are excluded.

## Architecture
Inno Setup packages a payload with `AutoModules.exe`, `python/`, `app/`, `host/`, `defaults/` and `prerequisites/`. CPython 3.12.10 embeddable runtime plus pinned wheel dependencies avoids copying a path-bound virtualenv. Host and launcher are .NET 8 win-x64 self-contained. A native launcher sets per-user `AUTO_MODULES_DATA_DIR`, seeds absent defaults, and starts `python/pythonw.exe app/main.py` from a stable working directory. Runtime code remains in the installation directory; maps, profiles, configuration and logs live under LocalAppData/AutoModules/Workbench. Development mode retains current paths when the environment variable is absent. Receiver identities remain independently generated by LanInputSync.

## Build and verification
Build sources are separate from developer files. Source assets and dependency versions are manifest-driven; downloads record hashes/provenance and driver signature checks fail closed. Output excludes Git, logs, credentials, __pycache__, editable imports and unrelated virtualenv packages. Test path relocation (including spaces/non-ASCII), clean dependency imports with PATH/PYTHONPATH sanitized, host/launcher self-contained invocation, actual installer UI and safe install/upgrade/uninstall behavior where possible. A clean second PC and real-game/driver-install tests remain explicitly separate if unavailable. Unsigned project installer may display Windows reputation warnings; no bypass or signing claim.

## 一、项目整体架构

### 1.1 项目定位

**实时小地图拼接系统** - 基于计算机视觉的实时游戏地图重建系统，支持火炬之光、流放之路等 ARPG 游戏。

### 1.2 核心技术栈

| 技术领域 | 技术选型 | 作用 |
|---------|---------|------|
| GUI 框架 | PySide6 | 用户界面、事件处理 |
| 视觉算法 | OpenCV 4.5+ | 图像处理、相位相关配准 |
| 数值计算 | NumPy | 矩阵运算、数组处理 |
| 屏幕捕获 | MSS / PIL | 高性能屏幕截图 |
| 输入模拟 | ctypes (WinAPI) | 鼠标控制（导航功能） |

### 5.2 HSV 识别器模块 (core/recognizer_optimized.py)

**类：HSVRecognizer**

#### 5.2.1 参数管理方法

| 方法名 | 签名 | 功能 |
|-------|------|------|
| `get_params` | `def get_params() -> dict` | 获取所有参数为字典 |
| `set_params` | `def set_params(params: dict)` | 动态设置参数（支持部分更新） |

#### 5.2.2 图像预处理方法

| 方法名 | 签名 | 功能 | 算法细节 |
|-------|------|------|----------|
| `_preprocess_for_wall` | `def _preprocess_for_wall(img) -> np.ndarray` | 墙体提取预处理（激进增强） | Gamma→CLAHE→TopHat→截断拉伸→深化 |
| `_preprocess_for_fog` | `def _preprocess_for_fog(img) -> np.ndarray` | 迷雾提取预处理（温和增强） | 模糊→对比度拉伸→轻微深化 |
| `preprocess_image` | `def preprocess_image(img) -> np.ndarray` | 默认预处理接口 | 调用_for_wall |
| `get_raw_gray` | `def get_raw_gray(img) -> np.ndarray` | 获取特征匹配用灰度图 | 预处理 + 转灰度 + 掩盖中心 |
| `_compute_transparency_score` | `def _compute_transparency_score(img) -> np.ndarray` | 透明地图特征分数计算 | V - S×penalty + TopHat |

#### 5.2.3 特征提取方法

| 方法名 | 签名 | 返回值 | 功能 |
|-------|------|--------|------|
| `extract_walls` | `def extract_walls(img, is_processed=False) -> np.ndarray` | 二值 mask | 提取墙壁层 |
| `extract_fog` | `def extract_fog(img, is_processed=False) -> np.ndarray` | 二值 mask | 提取迷雾层 |
| `extract_player` | `def extract_player(img, is_processed=False) -> np.ndarray` | 二值 mask | 提取玩家标记 |
| `extract_combined` | `def extract_combined(img, player_pos=None) -> tuple` | (match_mask, wall_mask, fog_mask) | 组合特征提取（核心接口） |
| `get_preprocessed_image` | `def get_preprocessed_image(img) -> np.ndarray` | BGR 图像 | 获取预处理后图像（用于显示） |
| `_filter_small_components` | `def _filter_small_components(mask, min_area=20) -> np.ndarray` | 过滤后 mask | 连通域分析去噪 |

**定位**：图像处理核心，负责从游戏小地图截图提取可用于配准的特征。

**核心算法流程**：
```
原始截图 → Gamma 压暗 → CLAHE 增强 → TopHat 结构提取 → 截断拉伸 → 颜色深化
                                    ↓
                    HSV 颜色分割 / 透明度分数计算 / Canny 边缘
                                    ↓
                         融合权重 → match_mask（配准用）
                                    ↓
                         wall_mask（保存用）+ fog_mask
```

**关键设计**：
1. **透明地图模式**：使用 `V - S×penalty` 公式提取灰白色线条
2. **饱和度过滤**：去除彩色玩家箭头（支持全局/局部过滤）
3. **三掩码输出**：match_mask 用于配准，wall_mask 用于保存，fog_mask 用于显示

| 方法名 | 签名 | 功能 |
|-------|------|------|
| `save_map_package` | `def save_map_package(folder_path)` | 保存地图数据到 npz |
| `load_map_package` | `def load_map_package(folder_path) -> bool` | 加载地图数据 |
| `reset` | `def reset()` | 重置拼接器 |

**定位**：整个系统的核心算法引擎，负责将连续帧拼接成完整地图。

**核心算法流程**：
```
add_frame() 调用
    │
    ▼
┌─────────────────────────────────────────────────────────┐
│ 1. 第一帧？→ 初始化关键帧和上一帧                        │
├─────────────────────────────────────────────────────────┤
│ 2. 配准阶段 (Registration)                              │
│   ├─ A. 尝试与关键帧匹配 (Anchor Matching)              │
│   │   └─ 成功 → 位置 = 关键帧位置 - 位移×缩放           │
│   │   └─ 失败 → 进入 B                                  │
│   └─ B. 尝试与上一帧匹配 (F2F Fallback)                 │
│       ├─ 成功 → 位置 = 当前位置 - 位移×缩放             │
│       │         → 特征足够？更新关键帧                  │
│       └─ 失败 → 记录失败，位置不变                      │
├─────────────────────────────────────────────────────────┤
│ 3. 绘制阶段 (Drawing)                                   │
│   ├─ 缩放 save_mask 和 fog_mask 到 draw_scale           │
│   ├─ 计算目标区域 ROI                                    │
│   ├─ 相似度检测（防止重复绘制）                         │
│   ├─ 权重层更新：roi_weight[new_wall] += weight_add     │
│   ├─ 可见墙判定：weight > 1.0                           │
│   └─ 写入 wall_layer 和 explored_map                    │
└─────────────────────────────────────────────────────────┘
```

**关键帧锚点策略**：
```
关键帧匹配成功 (质量>0.25)
    │
    ▼
保持当前关键帧，直接计算位置
    │
    ▼
关键帧匹配失败
    │
    ▼
尝试上一帧匹配 (质量>0.30)
    │
    ├── 成功 → 特征分数>500？→ 更新关键帧
    │              └── 否 → 仅 F2F，不更新锚点
    │
    └── 失败 → 配准失败，等待下一帧
```

**加权融合抗噪原理**：
```
单帧权重增量 = 0.3
可见阈值 = 1.0
最大权重 = 5.0

帧 1: weight = 0.3 → 不可见 (<1.0)
帧 2: weight = 0.6 → 不可见
帧 3: weight = 0.9 → 不可见
帧 4: weight = 1.2 → 可见！(>1.0)
...
帧 17: weight = 5.0 → 达到上限

结论：需要 4 帧确认才能显示墙体，单帧噪点被自然过滤
```

**类：PathFinder**

|-------|------|------|

**关键设计**：
- 降采样优化：6000×6000 地图 → 600×600 网格（因子 10）
- 安全边距：墙壁膨胀防止贴边移动
- 8 方向移动：支持斜向路径

### 8.1 导航核心模块 (core/navigation_core.py)

**类：NavigationCore** - 导航模式视觉定位核心

#### 8.1.1 数据结构

#### 8.1.2 核心方法

| 方法名 | 签名 | 功能 |
|-------|------|------|
| `__init__` | `def __init__(map_folder_path, center_offset_y=0)` | 加载地图数据 |
| `_load_map_data` | `def _load_map_data()` | 从 npz 加载地图 |
| `set_center_offset` | `def set_center_offset(center_offset_y)` | 设置中心偏移 |
| `set_initial_hint` | `def set_initial_hint(pos)` | 设置初始位置提示 |
| `_estimate_displacement` | `def _estimate_displacement(img1, img2)` | 相位相关位移计算 |
| `localize` | `def localize(minimap_img)` | **核心接口**：实时定位（F2F+ 模板匹配） |
| `get_map_image` | `def get_map_image()` | 获取渲染地图（自动裁剪） |

**定位策略**：
1. 已定位 + 有 prev_mask → F2F 跟踪（相位相关）
2. 未定位/无 prev_mask → 模板匹配（局部/全局搜索）

**定位**：导航模式的核心，负责从预保存的地图数据中进行实时视觉定位。

**定位策略流程**：
```
localize(minimap_img) 调用
    │
    ▼
1. 提取特征：extract_combined() → wall_mask, match_mask
    │
    ▼
2. 策略分支：
    │
    ├── 已定位 + 有 prev_mask → F2F 跟踪（相位相关）
    │       │
    │       ├── 成功 (qual>0.1) → 位置 -= 位移×draw_scale
    │       └── 失败 → 进入模板匹配
    │
    └── 未定位/无 prev_mask → 模板匹配
            │
            ├── 局部搜索模式（有 hint）
            │   └─ 在当前位置±300px 范围内搜索
            │
            └── 全局搜索模式
                └─ 在整个 wall_layer 上搜索
            │
            ▼
        cv2.matchTemplate(TN_CCOEFF_NORMED)
            │
            ▼
        max_val >= 0.6？
            ├── 是 → 定位成功，返回 (x, y, conf)
            └── 否 → 定位失败，降级为全局搜索
```

**关键设计**：
1. **双模式定位**：F2F 跟踪（快）+ 模板匹配（稳）
2. **局部搜索优化**：在 hint 位置附近搜索，减少计算量
3. **缩放匹配**：wall_mask(1x) → 放大到 2x 匹配 wall_layer
4. **自动裁剪**：get_map_image 自动裁剪有效区域并记录 offset

```
global_dist = 200px
draw_scale = 2.0
k_ratio = 10.0

minimap_dist = 200 / 2.0 = 100px (小地图上的距离)
screen_dist = 100 * 10.0 = 1000px (屏幕上的点击距离)
```

**定位**：将导航路径转换为屏幕鼠标点击操作。

### 15.2 核心算法流程

**绘图模式（建图）**：
```
屏幕捕获 → HSV 识别 → 特征提取 → 相位相关配准 → 加权融合 → 地图保存
  │          │           │            │            │          │
capture  recognizer  extract_    stitcher    merge      npz_save
                     combined
```

**导航模式（定位 + 移动）**：
```
屏幕捕获 → HSV 识别 → 模板匹配/相位相关 → 全局坐标 → 路径规划 → 鼠标控制
  │          │           │                   │          │          │
capture  recognizer  localize(NavCore)   pathfinder  controller  InputDriver
```

### 15.3 关键算法与技术

| 技术领域 | 算法/技术 | 应用场景 |
|---------|----------|---------|
| 图像配准 | 相位相关 (Phase Correlation) | 帧间位移计算 |
| 图像配准 | 模板匹配 (TM_CCOEFF_NORMED) | 全局/局部定位 |
| 图像分割 | HSV 颜色空间分割 | 墙体/迷雾/玩家提取 |
| 图像增强 | CLAHE (自适应直方图均衡) | 对比度增强 |
| 图像增强 | TopHat 变换 | 细微结构提取 |
| 图像增强 | Gamma 校正 | 中间调压暗 |
| 图像滤波 | 高斯模糊 + 形态学操作 | 去噪和平滑 |
| 特征融合 | 加权融合 (Weighted Merge) | 抗噪地图构建 |
| 寻路算法 | A* (降采样网格) | 路径规划 |
| 输入模拟 | Windows API (SetCursorPos, mouse_event) | 鼠标控制 |

```python
    def __init__(self, canvas_size=6000, draw_scale=2.0)
    
    # 参数管理
    def set_params(self, params: dict) -> None
    def get_params(self) -> dict

                  raw_gray=None, player_pos=None) -> bool
    
    # 配准算法
    def _estimate_displacement(self, img1, img2) -> tuple  # (shift, quality)
    def _smooth_displacement(self, dx, dy, quality) -> tuple
    def _place_first_frame(self, save_mask, fog_mask, px, py) -> None

    def _merge_frame_weighted(self, save_mask, fog_mask, h, w, px, py, force=False)

    def _is_too_similar(self, roi_wall, save_mask) -> bool

    def save_map_package(self, folder_path) -> None
    def load_map_package(self, folder_path) -> bool
```

**配准策略**：
```
关键帧匹配 (质量>0.25) → 位置 = 关键帧位置 - 位移×缩放
    │
    └── 失败 → 上一帧匹配 (质量>0.30)
            │
            ├── 成功 → 位置 = 当前位置 - 位移×缩放
            │         └── 特征>500？→ 更新关键帧
            │
            └── 失败 → 位置不变，记录失败
```

**加权融合抗噪原理**：
```
单帧权重增量 = 0.3
可见阈值 = 1.0
最大权重 = 5.0

需要 4 帧确认才能显示墙体 (0.3×4=1.2)，单帧噪点被自然过滤
```

### 18.7 配置文件结构

```json
{
    "monitor_logical_center": [147, 158],      // 逻辑中心坐标
    "monitor_size": 200,                        // 截图尺寸
    "monitor_region": null,                     // 物理区域（与逻辑中心互斥）
    "fps": 30,                                  // 帧率
    "recognizer_params": { ... },               // HSV 识别器参数
    "stitcher_params": { ... }                  // 拼接器参数
}
```

**map_data/[地图名称]/config.json** - 地图专属配置：
```json
{
    "draw_scale": 2.0,                          // 绘制缩放比例
    "monitor_logical_center": [x, y],           // 逻辑中心
    "monitor_size": 200,                        // 截图尺寸
    "fps": 10,                                  // 导航帧率
    "nav_preferences": { ... },                 // 导航偏好
    "recognizer_params": { ... }                // 识别器参数
}
```

**map_data/[地图名称]/map_data.npz** - 地图数据文件：
- `canvas` - 显示画布
- `weight_layer` - 权重累积层
- `explored_map` - 已探索区域
- `wall_layer` - 墙壁层
- `fog_layer` - 迷雾层
- `current_pos` - 最后位置
- `canvas_size` - 画布尺寸

### 18.9 模块间通信模式

#### 18.9.1 应用上下文模式 (AppContext)

```
MainWindow
    │
    └── AppContext (单例模式)
            ├── screen_capture: ScreenCapture
            ├── recognizer: HSVRecognizer
            ├── stitcher: MapStitcher
            ├── tracker: PlayerTracker
            └── path_finder: PathFinder

MappingWidget / NavigationModeWidget
    │
    └── 通过 app_context 引用共享核心模块
```

#### 18.9.2 信号 - 槽模式 (Qt Signal-Slot)

| 发送者 | 信号 | 参数 | 接收者 | 槽函数 |
|-------|------|------|-------|--------|
| TransparentOverlay | `region_selected` | (x, y, w, h) | MappingWidget | `on_region_selected()` |
| CenterPointSelector | `point_selected` | (x, y) | MappingWidget | `on_center_selected()` |
| ClickableImageLabel | `pixel_clicked` | (x, y) | ColorPickerDialog/MappingWidget | `on_pixel_clicked()`/`on_map_click()` |
| ScalableMapWidget | `pixel_clicked` | (x, y) | MappingWidget | `on_map_click()` |
| NavParametersDialog | `parameters_changed` | (NavConfig) | NavigationModeWidget | `_on_parameter_changed()` |
| NavParametersDialog | `save_requested` | - | NavigationModeWidget | `_save_nav_config()` |
| QTimer | `timeout` | - | MappingWidget/NavigationModeWidget | `capture_and_process()`/`navigation_loop()` |

#### 18.9.3 直接调用模式

```
# 核心算法链路
MappingWidget.capture_and_process()
    │
    ├── app_context.screen_capture.capture_square()
    ├── app_context.recognizer.extract_combined()
    ├── app_context.stitcher.add_frame()
    └── app_context.tracker.detect_player()

# 导航控制链路
NavigationModeWidget.navigation_loop()
    │
    ├── app_context.screen_capture.capture_square()
    ├── nav_core.localize()
    │       └── recognizer.extract_combined()
    └── motion_controller.update()
            └── input_driver.click()
```
